Gathrd.
Church Operating System for Nigeria

Gathrd is a full-featured SaaS platform built specifically for Nigerian churches of all denominations and sizes. It replaces scattered WhatsApp groups, manual registers, and paper envelopes with one unified system that handles every administrative function a church actually needs.

From attendance tracking via QR code and WhatsApp, to member management, tithe records, event coordination, and group communication — Gathrd is the operating system underneath the ministry. Built with React, Supabase, Paystack, Termii, and WhatsApp as the primary notification channel.
